เกมทำอาหารบนเบราว์เซอร์ รองรับ Solo และ local co-op 2–5 คนบนจอเดียวกัน

เปิด `index.html` โดยตรงเพื่อเล่น Solo หรือสองคนด้วยคีย์บอร์ด หากต้องการใช้โทรศัพท์เป็นจอย ให้เชื่อมทุกเครื่องกับ Wi-Fi/hotspot เดียวกันแล้วรัน:

```sh
cd server
npm install
npm start
```

เปิด URL ที่แสดงบนคอม เลือก “เล่นหลายคนเครื่องเดียว” แล้วกด “สร้าง QR” ให้โทรศัพท์สแกน ผู้เล่นคีย์บอร์ด 1 ใช้ `WASD` + `E`, `Q` ใช้สกิล และ `R` ล้างวัตถุดิบที่เตรียมไว้ในสถานี; ผู้เล่นคีย์บอร์ด 2 ใช้ลูกศร + `Enter`, `\\` ใช้สกิล และ `-` ล้างสถานี โทรศัพท์และ touch controls มีปุ่ม `ทิ้ง` สำหรับการทำงานเดียวกัน
